LESSON 01

See the complete stack.

The agent is not “a smarter model.” It is a control loop around a model. Each layer has a different job—and a different failure mode.

1You

State the goal, scope, files, and approval boundary.

→
2Hermes Agent

Plans, selects tools, inspects results, and continues.

→
3Ollama

Serves the chosen model through a local endpoint.

→
4Your machine

Runs commands, reads permitted files, and stores local state.

MODEL

The reasoner

Generates language and tool calls. It needs enough context and reliable tool-call support.

TOOLS

The hands

Filesystem, terminal, search, browser, and integrations. Permissions set the real blast radius.

LOOP

The operator

Executes an allowed tool, returns the result to the model, and repeats.

MEMORY

The continuity

Local cross-session notes and conversation retrieval. Useful, but still reviewable.

SKILLS

The playbooks

Reusable procedures that keep recurring work from starting at zero.

GATEWAY

The remote door

Optional messaging access. Add it only after the local terminal loop works.

LESSON 03

The model is the hardware decision.

Agent work includes a system prompt, tool schemas, conversation state, and tool results. Hermes’s current local guidance requires an effective context window of at least 64,000 tokens for tool use.

Setup direction

This does not benchmark the PC; it chooses a conservative path.

CONSERVATIVE VERDICT

Measure before another large download.

You can install and open Hermes now, but do not commit to a large local model until you know system RAM and GPU VRAM.

Get-CimInstance Win32_ComputerSystem | Select-Object @{N='RAM_GB';E={[math]::Round($_.TotalPhysicalMemory/1GB)}} Get-CimInstance Win32_VideoController | Select-Object Name,@{N='VRAM_GB';E={[math]::Round($_.AdapterRAM/1GB,1)}}
64K

hermes3:8b proves local inference—not full agent readiness.

Keep it for chat and testing. But tool reliability and effective context are separate requirements. If Hermes rejects it or cannot complete tool calls, choose a supported tool-capable model rather than forcing the old one.

A model is ready when

  • Hermes accepts its effective context.
  • It emits valid tool calls, not prose pretending to be one.
  • It can read a tool result and continue.
  • Your machine remains responsive.

Stop and switch when

  • It only chats but never invokes a tool.
  • Context is below the minimum.
  • It loops on the same failed action.
  • Windows swaps or freezes.

Make the first action reversible.

Do not begin with email, finances, brokerage files, or your home folder. Start in a disposable directory and require a plan before any write.

Sandbox folder
PS $HOME\hermes-sandbox> hermes
03

Inspect before action

First agent prompt
Work only inside the current hermes-sandbox folder. First tell me the current path and list its contents. Do not write or delete anything yet. Then propose a three-step plan to create a plain-text study outline about how an AI agent differs from a chat model. Wait for my approval before creating the file.
04

Approve one bounded write

Verify the reported path. Approve only the proposed text file. Inspect the result yourself before expanding permissions.

✓

Success is observable

Hermes reports the real path, lists the folder, pauses for approval, creates only the agreed file, reads it back, and stops.

LESSON 05

Add capability one layer at a time.

The impressive multi-agent demos are assembled from tools, skills, memory, schedules, and gateways. You do not need all of them on day one.

Tools: the ability to actstart here

Begin with terminal and file work in a sandbox. Add browsing or external connectors only for a specific task.

Operating rule
Before using any tool, state the action, exact target, and whether it is read-only, reversible, or destructive. Ask before any destructive action, external send, installation, credential use, or access outside the current folder.
Memory: continuity across sessionsreview

Use memory for stable preferences and project conventions. Ask what will be remembered, remove stale entries, and never store passwords, recovery codes, or private keys.

Skills: repeatable workflowsafter repetition

Encode a workflow only after you have tested it. Start with a narrow procedure, such as turning a folder of notes into a fixed outline.

Gateway: talk from another appoptional

Set up one messaging channel only after local chat works and you have a real remote-use case.

Later
PS> hermes gateway setup
Multiple roles: bounded specialistsadvanced

Separate coding, research, and life-admin work with distinct briefs and folders. The boundaries reduce context contamination; the labels do not make the roles independent people.

LESSON 06

Permissions are the product.

An agent’s practical power comes from tools and credentials. A small model with broad shell access can do more damage than a large model confined to a scratch folder.

Keep enabled

  • Plan-before-action for consequential work.
  • Approval before sends or deletion.
  • A dedicated project folder.
  • Logs you can inspect.

Never paste

  • Passwords, API keys, recovery codes, or private keys.
  • Full account or government ID numbers.
  • Credentials copied from config files.
  • Data you are not authorized to process.
LESSON 07

Diagnose the layer that failed.

Do not reinstall everything because one prompt failed. Match the symptom to PowerShell, Hermes, Ollama, the model, or the tool.

PowerShell says ollama launch is unknown

Your Ollama build may not include the launch integration. Use the native installer in Lesson 02, open a new terminal, and run hermes.

PowerShell says hermes is unknown

Open a new terminal so User PATH reloads. Native Hermes installs under %LOCALAPPDATA%\hermes. If it still fails, rerun the installer and read its final error.

Hermes cannot see Ollama

Verify Ollama is running, then reopen model configuration.

PowerShell
PS> ollama list
PS> hermes model

For manual setup, use http://127.0.0.1:11434/v1 and leave the API key blank.

Hermes rejects the context length

The effective context is below 64K. Choose a model/runtime configuration that can truly serve 64K; do not merely type a larger number into Hermes.

The agent talks about a tool but never uses it

The model may not support reliable native tool calls. Switch with hermes model. A sentence claiming “I created the file” is not proof—inspect the filesystem.

The machine becomes unusably slow

Stop the run, choose a smaller compatible model, or use cloud inference temporarily to learn the agent layer. A successful download does not mean the machine can serve the model well.

↻

Change the model later

Use hermes model. The agent installation, sessions, memory, and skills are separate from the model choice.
