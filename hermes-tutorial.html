LESSON 01

Know what is doing what.

Most confusion disappears when you separate the model, the runtime, the interface, and the agent. They are different layers.

MODEL

Hermes 3:8B

The language model. It predicts useful text from your input and context. It is not automatically connected to your files, the web, or your accounts.

RUNTIME

Ollama

The engine that stores and runs the model on Windows. It also exposes a local API at localhost:11434.

INTERFACE

PowerShell

Your first control surface. Simple and transparent: type a command, see the result, know exactly which model is running.

CONTEXT

The working packet

The instructions and documents supplied in the current conversation. More context is not always better; relevant context is better.

AGENT

Model + tools + loop

An agent can choose actions, use tools, inspect results, and continue. A chat model alone only responds to what you give it.

GROUNDING

Evidence in, claims out

For account facts, current markets, law, health, or citations, supply verified source material and require the model to stay inside it.

!

Hermes 3 is not “Hermes Agent” by itself.

You have downloaded the Hermes 3 model through Ollama. That gives you local chat and a local API. Autonomous tools, browsing, and file actions require a separate agent layer and careful permissions.

LESSON 02

Run, inspect, and benchmark.

Treat the first session like a systems check. Confirm the model exists, confirm it answers, then see whether your old Windows machine can run it comfortably.

01

Confirm the model is present

ollama list should show hermes3:8b. If it is absent, the download did not finish.

PowerShell
PS> ollama list
02

Use a diagnostic prompt

A good test checks instruction-following, structure, and honesty—not trivia.

Paste inside Hermes
You are being tested as a local model. Return exactly:
1. One sentence defining a context window.
2. One fact you cannot verify without a source.
3. One clarifying question you would ask before analyzing a brokerage dispute.
Do not add an introduction.
03

Watch the machine, not just the prose

Open Task Manager → Performance. Watch memory, CPU, and GPU while it answers. Slow first-token time is normal on CPU; freezing, swapping, or sustained memory pressure means the model is too heavy for the workload.

04

Know the practical hardware tiers

8 GB system RAM: tight for an 8B model; close other apps. 16 GB: generally workable. 32 GB: much more comfortable for longer context. GPU memory changes speed; it does not change whether the answer is true.

Healthy first run

  • The model answers the requested format.
  • Windows remains responsive.
  • Repeated prompts do not crash Ollama.
  • ollama ps shows the active model.

Stop and simplify

  • The machine swaps heavily or locks up.
  • Answers truncate during short prompts.
  • Long context makes response time unusable.
  • You are tempted to expose port 11434 to the internet.
LESSON 03

Prompt like an engineer, not a magician.

The best prompt is a compact specification. Give Hermes a role, a bounded task, the evidence it may use, the output shape, and tests it must pass.

CContext

Why this matters, what happened, and what the model needs to know.

RRole

The lens to use: tutor, reviewer, analyst, editor—not a claim of authority.

AAssignment

One specific job with a clear finish line.

FFormat

The exact sections, length, tone, or schema you want back.

TTests

Constraints the answer must satisfy before it is done.

Weak → strong
Weak:
Help me win my broker dispute.

Strong:
CONTEXT: I am evaluating a broker dispute from a chronology and account statements I will paste.
ROLE: Act as a skeptical evidence analyst, not my advocate.
ASSIGNMENT: Separate supported facts, disputed claims, and missing proof.
FORMAT: Three sections—Established, Contested, Missing—with bullet points.
TESTS: Cite each conclusion to a date or exhibit label. Do not invent law, damages, or account activity. Write “not established” when the record is insufficient.
∴

The CS50 rule: isolate the bug.

If an answer is wrong, change one variable at a time. Shorten the evidence, tighten the output, lower creativity, or split the task. Do not rewrite everything and then wonder what fixed it.

LESSON 04

Six useful jobs for your actual life.

Each pattern gives Hermes a bounded lane. Open one, copy the prompt, and replace the bracketed fields with a redacted, source-grounded packet.

Trading thesis red teamanalysis

Use Hermes to challenge your reasoning—not to supply live quotes, earnings, or valuations it cannot verify.

Prompt pattern
You are a skeptical investment committee member. Analyze only the source packet below. My thesis is: [THESIS].

Return:
1. Claims directly supported by the packet
2. Claims that rely on assumptions
3. The three strongest bear cases
4. What evidence would falsify the thesis
5. Questions that must be answered before sizing

Rules: No live-price claims. No invented financial metrics. Flag every missing date and source.

SOURCE PACKET:
[PASTE VERIFIED FILINGS, NOTES, OR DATA]
Dispute chronology auditevidence

Make the model reconcile dates and documents before it writes advocacy.

Prompt pattern
Audit this dispute chronology as if you oppose my position. Build a table with: date, event, source, amount, who made the claim, contradiction, and confidence. Then list: (a) duplicate or inconsistent figures, (b) unsupported legal conclusions, and (c) the five documents that would most strengthen the record. Use only the text I provide. Mask all account numbers except the last four.

RECORD:
[PASTE CHRONOLOGY AND EXHIBIT EXCERPTS]
Debt-settlement call debriefsales

Turn a rough recap into a precise next-action plan. Keep client details anonymized.

Prompt pattern
Turn this anonymized call recap into:
1. A factual CRM note
2. Primary objection
3. Buying signal
4. Next action with a concrete date placeholder
5. A concise follow-up email

Rules: Do not promise settlement amounts, timelines, credit outcomes, or creditor participation. Preserve uncertainty.

RECAP:
[PASTE REDACTED NOTES]
Coursework Socratic tutorlearning

Use the model to expose gaps in your understanding before drafting an answer.

Prompt pattern
Teach me [TOPIC] as a demanding business-school tutor. Start with a compact explanation, then ask one question at a time. Do not reveal the answer until I attempt it. After five questions, grade my reasoning and give me one transfer problem in a new business context. Use only the course material below for citations.

COURSE MATERIAL:
[PASTE NOTES OR ASSIGNMENT TEXT]
Routine and health reviewreflection

Summarize self-tracked patterns without turning a local model into a clinician.

Prompt pattern
Analyze the seven-day routine log below. Identify patterns in bedtime, wake time, steps, exercise, and self-reported energy. Separate observation from hypothesis. Propose one low-risk experiment for next week and define the success measure. Do not diagnose, prescribe, or infer missing health data.

LOG:
[PASTE A REDACTED WEEKLY SUMMARY]

Model scenarios from rounded, redacted numbers. Do not paste account credentials, full identifiers, or statements you do not need.

Prompt pattern
Using only the rounded figures below, compare the base, downside, and severe-downside scenarios. For each, calculate monthly surplus/deficit, months of liquid runway, and the first breached constraint. Show arithmetic. Do not assume investment returns or future income not listed. End with the smallest reversible action that improves the downside case.

LESSON 06

            
Turn one base model into specialists.
Ollama Modelfiles let you package stable instructions and conservative settings. The model weights stay the same; the default behavior changes.

          

          

            
01
Create a Modelfile
In a new folder, create a plain file named Modelfile with no extension. Start with an 8K context; raise it only if your machine remains responsive.
Modelfile
FROM hermes3:8b
PARAMETER temperature 0.2
PARAMETER num_ctx 8192

SYSTEM """
You are a rigorous evidence analyst.
Separate sourced facts, inference, and unknowns.
Never invent dates, citations, figures, or legal authority.
When evidence is insufficient, write: not established.
Prefer concise, structured answers.
"""

            
02
Build and run the specialist
PowerShell · inside that folder
PS> ollama create evidence-desk -f .\Modelfile
PS> ollama run evidence-desk

            
03
Call Hermes from PowerShell
The local API lets you automate repeatable work without a paid service. This example sends one prompt and returns one completed response.
PowerShell · local API
$body = @{
  model = 'hermes3:8b'
  prompt = 'Explain the difference between evidence and inference in 100 words.'
  stream = $false
} | ConvertTo-Json

$result = Invoke-RestMethod `
  -Uri 'http://localhost:11434/api/generate' `
  -Method Post `
  -ContentType 'application/json' `
  -Body $body

$result.response

            
04
Keep the API local
localhost means this machine. Do not open Ollama's port to the public internet. If another device needs access later, use a deliberate authenticated network design—not a firewall exception copied from a random tutorial.

Before you trust an answer
  • Can every consequential claim be traced to supplied evidence?
  • Did the model separate observation from inference?
  • Did arithmetic survive a calculator check?
  • Did it admit what the packet does not establish?

            
Never paste
  • Passwords, API keys, recovery codes, or private keys.
  • Full account, claim, policy, or government ID numbers.
  • Unredacted client records you are not authorized to process.
  • Anything you would not want copied into a transcript or log.
